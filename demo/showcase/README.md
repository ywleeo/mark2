# 官网与商店截图演示资料

`en/` 为全英文演示工作区，`zh/` 为中文演示工作区。截图只打开对应语言的子目录，避免路径、标题和侧栏混入其他语言。

这些是虚构的演示稿，不是客户资料，也不包含真实 API Key 或聊天记录。网页与应用截图必须来自真实 UI，不把示例内容作为真实用户证言。

- 01：配图文章，展示 Markdown 写作、Editorial、专注模式与大纲。
- 02：技术方案，展示表格、任务列表和 Mermaid 流程图。
- 03：学习笔记，展示 KaTeX 公式与表格。
- 04：短文，展示图片卡片导出。
- 05：代码样例，展示语法高亮。
