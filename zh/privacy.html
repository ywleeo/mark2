隐私政策

生效日期：2026 年 11 月 19 日
开发者：Yuwei Li（ywleeo）
适用于 Mark2 桌面应用及本网站。

除非你选择使用需要共享内容的功能，文稿保留在设备上。Mark2 无需开发者账号，AI 和 GitHub 分享均为可选功能。Mac App Store 版采用一次购买、无订阅的模式；AI 服务费用由你选择的服务商另行收取。

1. 本地文稿与应用数据

Mark2 读取并编辑你打开的文件，把文稿与导出结果保存到你选择的位置。设置、工作区和最近文稿记录、文档关联的 AI 对话、恢复副本、版本历史与保险箱数据保存在本地。数据可能在会话结束后保留，关闭文稿或卸载应用不一定清除设置、恢复数据和导出文件。

恢复副本和版本历史可能包含文稿的旧内容，当前实现为每份文稿保留最多 20 条历史记录。从文稿库移除记录不会删除源文件。请通过操作系统删除文稿和导出文件，通过设置移除凭据，通过保险箱删除其中的条目。如需清除其他本地应用数据，请先退出 Mark2，再移除其应用数据与 WebView 网站数据；商店版还包括沙盒容器。操作前备份文稿，可通过下方渠道询问具体路径。

商店版使用 macOS App Sandbox，访问容器外文件或文件夹需要操作系统授权。应用保存的文件访问书签可能让你在之后重新打开已授权的文稿。

2. 可选 AI 服务

你自行选择服务商或兼容网关，并提供自己的 API Key。发送请求前，Mark2 会请求向对应服务 origin 共享数据的许可。请求可能包含提示词、选中文字、相关文稿、对话历史及完成任务所需的上下文。启用并使用续写建议时，也会发送相关上下文；API Key 用于请求认证。

预设服务包括 OpenAI、DeepSeek、阿里云百炼（通义千问）、MiniMax、智谱 GLM、Google Gemini 与火山引擎豆包。自定义网关还可能转发给其他服务商。第三方的保留期限、训练用途、安全措施、跨境处理及删除方式由其政策与账户设置决定，Mark2 无法控制。发送敏感内容前，请阅读实际接收方的政策。

  • OpenAI · DeepSeek
  • 阿里云 · MiniMax
  • 智谱 · Google · 火山引擎

你可以拒绝共享，或在设置中撤回后续请求的授权，本地编辑仍可使用。撤回无法召回已发送或在途的数据；删除第三方持有的数据需通过其渠道办理。购买 Mark2 不包含 AI 额度。

3. 可选 GitHub Gist 分享

你主动发起并授权后，Mark2 使用你的 GitHub Token，将生成的 HTML 文稿和内嵌图片上传为 Secret Gist。Secret Gist 不是加密私密存储，获得链接的人可以读取或复制内容。请在 GitHub 上删除托管副本，但无法召回他人已经复制的内容。参见 GitHub 隐私声明。

4. 凭据与保险箱

AI API Key 与 GitHub Token 保存在本地应用设置（包括 WebView localStorage），并不自动使用保险箱加密。可以在设置中清除或替换，并向签发方撤销。能访问你的设备或备份的人，可能也能访问这些设置。

独立保险箱使用 AES-256-GCM 加密其中的条目，将主密钥保存在系统凭据存储中。这仅保护保险箱条目，不代表所有设置和文稿都经过相同加密。任何存储方式都无法保证在设备被攻破后仍然安全。

5. App Store 购买

Apple 通过你的 Apple 账户处理购买、付款和适用退款。Mark2 不接收支付卡信息，也没有开发者运营的订阅或收据验证服务器。商店版无循环订阅或应用内功能分层，此前免费获取的用户通过 Apple 分发系统保留使用权。参见 Apple 隐私政策。

6. 网络请求与网站托管

GitHub 版可以访问 Mark2 更新服务检查版本并下载更新；商店版通过 Apple 更新，不使用站外更新器。网络和托管服务商在被访问时会收到 IP 地址、请求时间与用户代理等连接信息。本网站由 GitHub Pages 托管，适用 GitHub 的政策。

当前桌面应用未集成第三方广告或行为分析 SDK，也不会自动把文稿或保险箱上传到开发者云服务。文稿可以引用远程图片或链接，加载图片或打开链接时，相应网站会收到连接信息。AI 和 Gist 的共享规则见前述章节。

7. 支持、选择与隐私请求

你联系开发者时主动提供的信息，用于回复和排查问题。GitHub issue 公开可见，请勿发布私人文稿、凭据、个人信息或私密日志。隐私请求可通过 开发者主页 联系，或提交一个不含敏感信息的 支持请求，先询问私密联系渠道。

根据你所在地的适用法律，你可能享有访问、更正、删除、限制或反对处理、获取可携带副本、撤回同意和向监管机构投诉等权利。我们只能处理开发者持有的信息；仅在本地的数据需在设备上管理，Apple、GitHub 或 AI 服务商持有的数据可能需要另行联系它们。第三方可能在你的国家或地区以外处理数据。Mark2 不面向 13 岁以下儿童。

8. 政策变更

更新后的政策会在本地址发布并修改生效日期。应用数据处理的重大变化也会写入对应版本的更新说明。
