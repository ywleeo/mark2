Mark2

A Markdown workspace for independent developers, technical writers, and creators. Read PDFs and code alongside your draft, turn your research into a proposal, tutorial, or article, and export it when you’re ready to share.

Two workspace layouts

Choose a layout in Settings → General → App Skin. Each layout has its own typography and colors, and both work with the same local files.

Classic

Keep the whole project in view.

A folder tree and tabs keep project files within reach. Move between a draft and its source code, or organize research and documentation together.

Monochrome Forest Iris

Editorial

Pick up where you left off.

My Documents lists your latest drafts by title, so you can find what you were working on at a glance. The editor gives one draft the full workspace.

Terracotta Pine Ink Indigo

Each layout remembers its own color palette.

Two ways to stay focused

Turn on either writing mode from the View menu, or use both together in either layout.

Focus Mode

Dim the surrounding text while you work on the current paragraph. Available in Markdown and code views.

Typewriter Mode

Keep the line you are writing near the center of the editor as the draft grows.

From research to finished draft

Read, draft, revise, and share in the same Markdown workspace.

Read your sources

Keep PDFs, code, images, and spreadsheets beside your draft. Refer to the implementation as you write a design note, or turn course materials into your own notes.

Write the first draft

Draft tutorials, documentation, and articles in visual Markdown. Switch to source when you want to edit the markup directly.

Organize the project

Move between project files in Classic, or give one piece your attention in Editorial. Both layouts open the same local files.

Add equations and diagrams

Put KaTeX equations and Mermaid flowcharts, sequence diagrams, state diagrams, or Gantt charts right in your Markdown.

Revise with optional AI

Continue at the cursor, polish or translate a selection, or discuss the current draft. Connect your own AI provider and API key when you want to use these tools.

Export and share

Export a finished draft or turn a passage into an image card. Connect your own GitHub token to share a link through Gist.

Keep your work safe

Recover unsaved work, revisit earlier drafts, and find the files you need.

Crash recovery

Mark2 keeps recovery copies in the background. If the app closes unexpectedly, recover unsaved work in the editor and review it before saving.

Version history

Preview earlier versions under File → Version History. A restored version opens as an unsaved edit for you to review.

Workspace search

Search across open files and folders, with case-sensitive, whole-word, and regular expression options. Jump directly to the matching text.

Vault

Items stored in the vault use AES-256-GCM encryption. The system keychain holds the master key.
