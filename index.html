Mark2

专注写作和阅读的 Markdown 桌面应用。小而快，安装包不到 30 MB。两种界面模式、两种写作模式，让应用跟着你的工作状态走；AI 不占一条常驻侧栏，而是贴着光标和选区工作。

⬇ 下载 macOS 版 ⬇ 下载 Windows 版 GitHub 仓库 安装包不到 30 MB

两种界面模式

同一套文档，两种工作方式。在「设置 → 通用 → 整体皮肤」里切换，皮肤只改变布局、排版气质和配色，不动你的文件。

两套皮肤各自记住自己的配色选择，切回去还是你熟悉的样子。

两种写作模式

界面模式决定「怎么管」，写作模式决定「怎么写」。两者都在「视图」菜单里，可以单独开，也可以叠加。

专注模式

当前段落保持正常显示，其余内容淡出，视线不会被上下文拽走。Markdown 和代码视图都支持。

打字机模式

正在写的那一行始终停在屏幕中央，长文写下去时不用一直低头看屏幕底部。

为什么用 Mark2

Mark2 的目标不是做一套庞大的知识系统，而是做一个小、快、简单、真正适合写作的 Markdown 工具。

AI 融入写作过程

在光标处续写、卡住时给灵感，对选中内容润色、扩写、精简、翻译，也能对着当前文档展开一轮对话。

界面跟着状态变

经典模式管文件，编辑部模式管文稿；专注与打字机模式让长文写作更稳，每套皮肤独立记住配色。

文档能力完整

除了 Markdown，还支持 PDF、代码、图片、音视频、表格和 Word 导入，围绕真实文档场景。

公式与图表

内嵌 KaTeX 公式与 Mermaid 流程图、时序图、状态图、甘特图，写技术内容、论文、笔记都顺手。

很小，也很快

基于 Tauri，底层是 Rust，安装包不到 30 MB。无需为写一篇文章打开沉重的工作台。

输出链路短

把笔记、观点、摘录或文章片段一键导出成卡片图，也可以生成 Gist 分享链接发给别人看。

界面一览

写作、阅读、AI 协作和卡片导出，都在一个轻量工作区里。

不怕丢稿

写作工具最该做好的事，是让你敢放心地写下去。

崩溃恢复

后台保存恢复副本，异常退出后重启会提示找回未保存的文稿；恢复只放回编辑器，不会直接覆盖磁盘文件。

版本历史

「文件 → 版本历史」可以预览这篇文档的历史版本，恢复后先成为未保存修改，确认内容再保存。

工作区搜索

在已打开的文件和文件夹里全文搜索，支持区分大小写、全字匹配和正则，结果直接高亮跳转。

保险箱

API Key 和账号密码用 AES-256-GCM 加密存在本地，主密钥交给系统钥匙串保管，复制后 30 秒自动清空剪贴板。

想先试试？仓库里的 demo/samples/ 放了几篇样稿：文章、技术方案、课程笔记和一个代码文件，直接用 Mark2 打开这个文件夹即可。
